# BMI Calculator

## About
A beginner-level Python project that calculates Body Mass Index (BMI) using weight and height.

## Features
- Calculates BMI using weight in kilograms and height in metres.
- Displays BMI rounded to two decimal places.
- Shows the category: Underweight, Normal, Overweight, or Obese.
- Handles invalid inputs and non-positive values.

## Formula
BMI = Weight (kg) / Height (m)²

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run `python main.py`.
4. Enter your weight and height when prompted.
