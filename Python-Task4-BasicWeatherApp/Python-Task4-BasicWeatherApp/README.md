# Basic Weather App

## About the Project
This is a beginner-friendly Python project developed as part of the Oasis Infobyte Python Programming Internship.

The Basic Weather App allows users to enter a city name and view its current weather information.

## Features
- Accepts a city name from the user.
- Finds the location using city coordinates.
- Displays current temperature.
- Shows feels-like temperature.
- Displays humidity.
- Shows wind speed.
- Provides weather conditions.
- Handles invalid city names and network errors.

## Technologies Used
- Python
- Open-Meteo API
- urllib
- JSON

## How to Run
1. Install Python.
2. Open the project folder.
3. Run `python main.py`.
4. Enter a city name to view its weather report.
